# Academic_performance_risk

Este proyecto es desarrollado como idea de tesis de la carrera de Ingeniería de Sistemas de Información.  
Consiste en predecir el riesgo de bajo rendimiento académico de estudiantes de nivel secundario, y puede ser empleado tanto por docentes como por estudiantes.

## Permite conocer:
- Predicción del riesgo de bajo rendimiento
- Insights sobre factores que afectan el desempeño académico
- Visualizaciones para seguimiento y análisis
